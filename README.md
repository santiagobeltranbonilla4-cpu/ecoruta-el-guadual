# EcoRuta El Guadual

Prototipo académico interactivo de EcoRuta El Guadual, elaborado para el ejercicio de **Metodologías de Software — Scrum**.

## Cómo abrirlo

La aplicación está contenida en `index.html`. Se puede descargar y abrir localmente en un navegador. Al activar **GitHub Pages** para la rama `main` y la carpeta `/(root)`, también podrá consultarse desde una dirección pública.

## Funcionalidades de la versión 4

- Mapa interactivo con estaciones demostrativas.
- Catálogo de especies, búsqueda y filtros.
- Pasaporte ecológico y diario de observaciones.
- Cronómetro, seguimiento manual de actividad y audioguía.
- Simulación de consulta de códigos QR.

**Alcance:** los códigos QR no se leen con la cámara; GPS, identificación mediante inteligencia artificial y conteo automático de pasos no están implementados. Los sonidos de aves se generan de forma sintética. Este prototipo no reemplaza herramientas reales de navegación en campo.
